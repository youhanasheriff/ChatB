# BitChat Desktop 0.1.0-preview.1 — early preview

An independent, open-source desktop project following Bitchat. This first public
preview is for **Apple Silicon Macs**. Windows and Linux are coming later; Intel
Mac downloads are not available in this release.

## Download and install

Download `BitChat-Desktop-0.1.0-preview.1-macos-arm64.zip` from the
[GitHub release](https://github.com/youhanasheriff/bitchat-desktop/releases/tag/v0.1.0-preview.1).
Unzip it, drag **BitChat Desktop.app** into Applications, and open it.

The app is **ad-hoc signed, not Developer ID signed or notarized**. macOS may
block the first launch. If you trust this release and choose to run it, first
attempt to open it, then use **System Settings → Privacy & Security → Open
Anyway**, confirm the app name, and authenticate when asked. This is an
exception for this app. See [Apple's instructions](https://support.apple.com/102445).

The app declares **macOS 13.0 or later**. This build was tested locally on macOS
26.6.2; older macOS versions have not been qualified. Bluetooth access is needed
for nearby mesh communication. Location, microphone, camera, and selected-file
access support optional features and are requested by the app as needed.

To check the download, place the `.zip` and matching `.zip.sha256` file together
and run `shasum -a 256 -c BitChat-Desktop-0.1.0-preview.1-macos-arm64.zip.sha256`.
Exact download bytes, logical app bundle bytes, and the SHA-256 digest are in the
accompanying `.json` manifest. These exclude data the app creates while running.

## In this preview

- Native SwiftUI desktop shell, persistent sidebar, mesh and location channels.
- Inline private/group conversations, people search, notices, peer verification,
  network topology, and settings screens.
- Terminal, Native Light, and Graphite appearances, with independent Bubble or
  Terminal conversation layout.
- Keyboard shortcuts and a clipboard review flow that requires confirmation.

This preview retains upstream Bluetooth, Noise, Nostr, and Arti/Tor code. These
are implementation foundations, not a guarantee of interoperability or a new
security audit. Real-device Bitchat interoperability, camera scanning, and all
network/permission flows still require qualification. The shared Rust desktop
core and Windows/Linux apps remain scaffolds. Do not rely on this preview for
safety-critical communication. There is no automatic updater.
